# Materials for the AIST / NEDO tutorial

The AIST / NEDO tutorial occured on Thursday December 11 at 9:00 to present the community on the capabilities of QuEra's upcoming Gemini-class quantum computers. It was presented by Dr. Jonathan Wurtz. This repository holds both the slide deck, as well as the tutorial notebook. The invitation to the seminar is [here](https://unit.aist.go.jp/g-quat/ja/events/2025/20251211_ABCI-Q_vol.2.html)

The talk is recorded and has been uploaded to AIST's [YouTube page](https://www.youtube.com/@aistchanneleng). Note that at the time of writing the talk has yet to be uploaded, and a future update will update the link.
